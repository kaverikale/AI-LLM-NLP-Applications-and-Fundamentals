# GenAI Applications and Fundamentals

Welcome to the **GenAI Applications and Fundamentals** course repository for Master's students.

This repository contains the lecture material and hands-on implementations covered throughout the course. The course follows a **progressive, use-case-driven approach**, where we build a single Generative AI application incrementally across multiple weeks.

Instead of implementing unrelated examples for every topic, we continuously enhance the same application by introducing new concepts and capabilities. This allows students to understand not only individual GenAI concepts, but also how these concepts come together to build a complete GenAI application.
